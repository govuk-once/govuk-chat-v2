# Skills

[Claude Code skills](https://code.claude.com/docs/en/skills) for working with
this repository. Run one in Claude Code by typing its name:

- `/spec` drafts a feature spec in [docs/specs](../../docs/specs) for review
  before implementation.
- `/draft-pr-review` reviews a pull request and drafts its findings on GitHub
  as a review, posted only when and how you choose.
- `/combine-dependabot-prs` combines the open Dependabot pull requests that
  pass CI into a single pull request.

The skills that use GitHub need the [GitHub CLI](https://cli.github.com/)
authenticated.
